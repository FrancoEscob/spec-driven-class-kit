# Procedencia y reutilización

Las nueve skills originales se obtuvieron de [mattpocock/skills](https://github.com/mattpocock/skills), commit `3cca18b368ae95cdbdebbff572ccafa662551015`, consultado el 10 de septiembre de 2026. Se conserva el texto íntegro de su licencia MIT en `LICENSE-MATT-POCOCK`. Las carpetas incluyen los recursos locales del upstream, no solo el archivo de entrada.

Adaptaciones del curso, registradas también en `skills-manifest.json`:

- `to-spec`: síntesis acotada, criterios explícitos, dudas visibles y plan técnico separado; evita una lista artificialmente extensa de historias. Actualiza metadatos.
- `grill-with-docs`: permite cargar las skills por archivo cuando no hay herramienta Skill y combinar con no-tecnico.
- `grilling`: investigación local cuando no existe delegación autorizada.
- `code-review`: revisión secuencial si el entorno no ofrece subagentes autorizados; conserva los dos ejes y exige indicar la limitación.
- `tdd`: red-green-refactor para coincidir con el curso; explica fronteras de pruebas sin depender de una décima skill upstream no incluida (`codebase-design`).

Las restantes skills conservan el contenido descargado. El manifiesto incluye hashes originales y de todos los archivos entregados. No hay actualización automática: revisar diferencias, dependencias y licencia antes de adoptar un nuevo commit. No se afirma que este paquete sea publicado o respaldado por Matt Pocock.

`no-tecnico`, las guías y el caso de tutorías fueron creados para esta clase. No se presentan como material de Matt Pocock. El autor del curso puede decidir su licencia pública antes de publicar un repositorio abierto. La descarga para alumnos forma parte de la distribución de esta clase.
