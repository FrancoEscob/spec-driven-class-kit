# ADR 0001 · Kit simplificado de la clase

Estado: vigente. Actualizado el 10 de septiembre de 2026.

Decisión: distribuir nueve skills base, un prompt de preparación propio y plantillas Markdown. setup-franco-skills reemplaza la preparación upstream. grill-with-docs registra decisiones sin requerir domain-modeling. TDD se ofrece aparte y solo se instala cuando se elige ese complemento.

La práctica principal implementa una aplicación local para gestionar hábitos, con tres estados de respaldo y comprobaciones. Los materiales anteriores de tutorías se archivaron fuera del kit de alumnos para mantener un único ejemplo.

Los proyectos nuevos usan `specs/<proyecto>/` con spec, plan, tickets y evidencia. `demo-en-vivo/issues/` conserva tickets preparados de referencia; no fija una convención oculta para todos los proyectos.
