# Vocabulario del proyecto

Para una práctica pequeña, registrar los términos necesarios junto a las decisiones en `specs/<proyecto>/decisiones.md`. Crear CONTEXT.md solo si resulta útil para separar un vocabulario que crece. No hace falta instalar domain-modeling ni crear ADRs por rutina.

El ejemplo de hábitos tiene su vocabulario en `demo-en-vivo/CONTEXT.md`. Las palabras del ejemplo no son reglas de todos los productos.
